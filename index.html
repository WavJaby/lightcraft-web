UNOFFICIAL COMMUNITY MIRROR

An easier way to try LightCraft

This site simply makes LightCraft easier to try without installing it. LightCraft is developed by the ArtCraft Team and contributors. This mirror is not operated or endorsed by them.

You are loading the official v0.2.1 WebAssembly module with a community bootstrap. The web and desktop apps share an editing engine, but their features are not identical.

  • Photos and the library stay in this browser. Keep original files and use File → Back Up Library…; browser storage is not a backup.
  • Browser storage can be cleared or evicted. This Pages site shares the wavjaby.github.io origin with other project sites; their scripts can access same-origin data.
  • Large photo libraries and raw processing use memory and GPU resources. The browser version is experimental; evaluate the official desktop app for production work.
  • Mobile scaling adjusts display size, not touch support. The official editor retains its own language; this host translates its notices and loading interface.

Based on the v0.2.1 source, not an exhaustive test of every editing feature. Keep backups and evaluate the official desktop app before production work.
